# RepLog Store Listing Draft

## Short description
Simple strength training tracker for workouts, sets, reps, weight, PRs and progress.

## Full description
RepLog helps lifters log workouts quickly and focus on progressive overload.

Track exercises, sets, reps, weight, workout history, bodyweight and personal records in a clean offline-first app.

Features:
- Fast workout logging
- Built-in exercise library
- Custom exercises
- Custom workout templates
- Smart exercise metadata for muscles and movement patterns
- Advanced set types, RPE, tempo and supersets
- Workout streaks and milestones
- Workout history with calendar overview
- Automatic PR badges
- Progress charts and estimated 1RM rankings
- Lifetime analytics for reps, sets, PRs and total load
- Movement and muscle balance analysis
- Basic recovery score and plateau watch
- Bodyweight tracking with rolling average and goal line
- Rest timer support
- Advanced plate calculator with custom gym plates
- Kilograms or pounds preference
- CSV export
- JSON backup and restore

RepLog stores workout data locally on your device. All listed features are included from the start with no account requirement and no subscription.
