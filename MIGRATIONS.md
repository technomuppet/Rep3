# RepLog Database Migrations

Current Room database version: **16**

The production migration chain is continuous from **1 → 16**. The checked-in Room schema artifact for the current database is `app/schemas/com.replog.data.db.AppDatabase/16.json`. Room schema JSON files are generated by KSP; do not hand-author historical artifacts.

## Version 1

Initial schema:

- exercises
- workout_sessions
- session_exercises
- set_logs
- workout_templates
- template_exercises

## Migration 1 → 2

Adds bodyweight tracking:

```sql
CREATE TABLE bodyweight_logs
```

## Migration 2 → 3

Adds smart exercise metadata, advanced set metadata and supersets.

Exercises:

```sql
primaryMuscles TEXT NOT NULL DEFAULT ''
secondaryMuscles TEXT NOT NULL DEFAULT ''
movementPattern TEXT NOT NULL DEFAULT ''
difficulty TEXT NOT NULL DEFAULT 'Intermediate'
```

Set logs:

```sql
setType TEXT NOT NULL DEFAULT 'Working'
rpe REAL
tempo TEXT
```

Session exercises:

```sql
supersetGroup TEXT
```

Index:

```sql
index_session_exercises_supersetGroup
```

## Migration 3 → 4

Adds local exercise media path:

```sql
mediaAsset TEXT NOT NULL DEFAULT ''
```

## Migration 4 → 5

Adds target fields to template exercises:

```sql
targetReps INTEGER NOT NULL DEFAULT 8
targetWeight REAL
```

## Migration 5 → 6

Adds persisted workout prescriptions:

```sql
CREATE TABLE workout_prescriptions
```

Fields:

- sessionId
- exerciseId
- source
- targetSets
- targetReps
- targetWeight
- adjustment
- reason
- createdAt

Indexes:

- sessionId
- exerciseId
- unique sessionId + exerciseId

## Migration 6 → 7

Adds performance indexes for release hardening:

```sql
CREATE INDEX index_workout_sessions_startTime ON workout_sessions(startTime)
CREATE INDEX index_workout_sessions_endTime ON workout_sessions(endTime)
CREATE INDEX index_set_logs_timestamp ON set_logs(timestamp)
CREATE INDEX index_set_logs_sessionExerciseId_setNumber ON set_logs(sessionExerciseId, setNumber)
CREATE INDEX index_exercises_name ON exercises(name)
```

## Migration 7 → 8

Adds architecture foundation storage for future Training DNA and knowledge graph systems:

```sql
CREATE TABLE training_dna_metrics
CREATE TABLE knowledge_graph_relations
```

Training DNA indexes:

```sql
index_training_dna_metrics_dimension
index_training_dna_metrics_subjectType
index_training_dna_metrics_subjectId
index_training_dna_metrics_dimension_subjectType_subjectId
```

Knowledge graph indexes:

```sql
index_knowledge_graph_relations_sourceType
index_knowledge_graph_relations_sourceId
index_knowledge_graph_relations_targetType
index_knowledge_graph_relations_targetId
index_knowledge_graph_relations_relationType
index_knowledge_graph_relations_sourceType_sourceId_targetType_targetId_relationType
```

## Migration 8 → 9

Adds rest-timer history:

```sql
CREATE TABLE rest_logs
```

Indexes:

- `sessionExerciseId`
- `setId`
- `startedAt`

## Migration 9 → 10

Adds workout scoring and set/session metadata:

- `workout_sessions.qualityScore`
- `workout_sessions.totalVolume`
- `workout_sessions.totalSets`
- `workout_sessions.totalReps`
- `workout_sessions.prCount`
- `session_exercises.notes`
- `set_logs.prType`
- `set_logs.completed`

## Migration 10 → 11

Adds the live Training DNA, progression, plateau, and recommendation tables:

- `training_dna_snapshots`
- `training_dna_progression_scores`
- `plateau_events`
- `recommendation_history`

## Migration 11 → 12

Adds post-workout rating:

```sql
ALTER TABLE workout_sessions ADD COLUMN sessionRating INTEGER
```

## Migration 12 → 13

Adds goals and status/creation indexes:

```sql
CREATE TABLE goals
```

## Migration 13 → 14

Adds the "Train Anyway" recovery override log:

```sql
CREATE TABLE rest_day_overrides
```

Columns: `timestamp`, nullable `recoveryScore`, nullable `recommendationReason`.

## Migration 14 → 15

Adds pinned/favourite templates:

```sql
ALTER TABLE workout_templates ADD COLUMN isFavorite INTEGER NOT NULL DEFAULT 0
```

## Migration 15 → 16

Removes abandoned prototype storage that is not used by the live product:

```sql
DROP TABLE IF EXISTS training_dna_metrics
DROP TABLE IF EXISTS knowledge_graph_relations
```

## Migration test coverage

`app/src/androidTest/java/com/replog/data/db/AppDatabaseMigrationTest.kt` covers the current release-hardening transitions:

- 6 → 7 performance indexes
- 8 → 9 rest logs
- 10 → 11 Training DNA/recommendation tables
- 11 → 12 session rating
- 12 → 13 goals
- 13 → 14 recovery overrides
- 14 → 15 favourite templates
- 15 → 16 prototype-table removal

The tests use `MigrationTestHelper` and validate against generated Room schema assets. A host with Java, the Android SDK, and the project dependencies is still required to execute instrumentation tests and regenerate missing historical schema JSONs; they should not be fabricated manually.

## Required QA

On an Android/JDK host, run:

```bash
./gradlew :app:testDebugUnitTest
./gradlew :app:connectedDebugAndroidTest
./gradlew :app:assembleDebug
```

Then verify on a real upgrade path from the last released database (currently v13):

- existing workouts, templates, exercise metadata, and prescriptions remain readable
- v13 → v14 creates `rest_day_overrides`
- v14 → v15 preserves templates and defaults `isFavorite` to false
- v15 → v16 removes only the abandoned prototype tables
- fresh install creates v16 schema
- API 35 edge-to-edge layout and rest-timer behavior are verified on Android 15
